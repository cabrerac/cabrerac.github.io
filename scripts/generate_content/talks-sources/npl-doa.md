title: "Data-Oriented Architectures"
description: AI systems work in practice, but their inner workings are often hard to understand, which creates intellectual debt. This talk traces one cause, the data dichotomy of current software architectures, and presents Data-Oriented Architectures as an alternative that makes data available by design. It closes with DOAgent, a data-oriented library for multi-agent systems, and exploratory results on which questions about a run can be answered after it ends.
