# Data Mining course: shared helper (26-udenar-data-mining)

## Swap randomisation

`swap_randomization.py` holds the week 1 pattern rule, written once: `support_floor`, `p95`, `swap_randomize`, `pair_counts`, `swap_null_counts` and `kept_pairs`. Settings: `SUPPORT_SHARE = 0.03`, `SUPPORT_MIN = 5`, `SWAPS_PER_ONE = 5`, `N_SAMPLES = 100`, `SEED = 7`. The L2 notebook and the group notebook copy it unchanged, so they run on their own in Colab. Only the standard library and numpy.

Course build scripts (Word templates, session plans, instructor notebooks, smoke tests) are private and live outside the public repo. The shared document helpers are in [`scripts/course_docs/`](../course_docs/).
