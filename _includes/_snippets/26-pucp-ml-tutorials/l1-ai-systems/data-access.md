<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-middle text-left" style="width: 40%">
                <p><b>The USGS earthquake catalog</b></p>
                <ul>
                    <li>Published by the United States Geological Survey</li>
                    <li>Secondary source: somebody else decided what to record and how</li>
                    <li>The <a href="https://earthquake.usgs.gov/fdsnws/event/1/" target="_blank" rel="noopener noreferrer">FDSN event API</a> returns a CSV for a region, a time window, and a minimum magnitude</li>
                    <li>Those three choices define the dataset we will assess today</li>
                </ul>
            </div>
            <div class="column vertical-middle text-left" style="width: 60%">

```python
base = "https://earthquake.usgs.gov/fdsnws/event/1/query"
parameters = {
    "format": "csv",
    "starttime": "2024-01-01",
    "endtime": "2025-01-01",
    "minmagnitude": "4.5",
}
query = "&".join(f"{k}={v}" for k, v in parameters.items())
url = f"{base}?{query}"
```
