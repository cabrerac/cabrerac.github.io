## Conclusions

<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-middle text-left" style="width: 100%">
                <ul>
                    <li>AI-based systems work in practice, but we do not always understand how they work. This is <b>intellectual debt</b>.</li>
                    <li>One cause is the <b>data dichotomy</b>: data-driven systems need data exposed, while current architectures hide it behind interfaces.</li>
                    <li><b>Data-Oriented Architectures</b> (DOAs) make data available by design, which supports traceability and interpretability.</li>
                    <li><b>DOAgent</b> brings these principles to multi-agent systems through shared records.</li>
                    <li>Early, exploratory results suggest that the architecture decides <b>which questions we can answer</b> about a run after it ends.</li>
                </ul>
