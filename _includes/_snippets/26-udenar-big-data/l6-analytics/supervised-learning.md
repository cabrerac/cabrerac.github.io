## Supervised Learning

<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-top text-left" style="width: 100%">
<br>
<p>Given a training set of <em><b>N</b></em> example input-output pairs</p>
<br>
$$
(x_1, y_1), (x_2, y_2), ..., (x_N, y_N)
$$
<br>
<p>Each pair was generated by an unknown function <em><b>f</b></em></p>
<br>
$$
y = f(x)
$$
<br>
<p>The goal is to discover a function <em><b>h</b></em> that approximates the true function <em><b>f</b></em>.</p>
</div>
        </div>
    </div>
</div>

## Supervised Learning

<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-top text-left" style="width: 100%">
<br>
<p><em><b>h</b></em> is called a hypothesis. We need to search for <em><b>h</b></em> in a hypotheses space <em><b>H</b></em> of possible functions</p>
<br>
$$
h \in H
$$
<br>
<p>A consistent hypothesis maps each input to the corresponding grounded truth</p>
<br>
$$
h(x_i) = y_i
$$
<br>
<p>We cannot expect exact match to the ground truth. We look for <b>a best-fit function</b> that generalises well.</p>
<br>
<p>The hypothesis <em><b>h</b></em> accurately predicts the outputs of unseen inputs (i.e., test set).</p>
</div>
        </div>
    </div>
</div>

## Supervised Learning

<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-top text-left" style="width: 100%">
<br>
<p>Our goal is to select a hypothesis <em><b>h</b></em> that will optimally fit future examples. <b>Future examples</b> will be like past examples (i.e., stationary assumption)</p>
<br>
<p>Each example has a the same prior probability distribution</p>
<br>
$$
P(E_j) = P(E_{j-1}) = P(E_{j-2}) = ...
$$
<br>
<p>Each example is independent of previous examples</p>
<br>
$$
P(E_j) = P(E_{j} | E_{j-1}, E_{j-2}, ...)
$$
<br>
<p>Examples that satisfy these equations are independent and identically distributed (i.e., iid).</p>
</div>
        </div>
    </div>
</div>

## Supervised Learning

<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-top text-left" style="width: 100%">
<br>
<p>Our goal is to select a hypothesis <em><b>h</b></em> that will optimally fit future examples. <em><b>h</b></em> is <b>optimally fit</b> if it minimises the error rate</p>
<br>
<p>The error rate is the proportion of times that <em><b>h</b></em> produces the wrong output for an example</p>
<br>
$$
h(x_i) \neq y_i
$$
<br>
<p>Finding a good hypothesis implies choosing a good hypothesis space <em><b>H</b></em> and optimising or finding the best hypothesis <em><b>h</b></em> at training.</p>
</div>
        </div>
    </div>
</div>

## Supervised Learning

<div class="rows" style="height: 100%">
    <div class="row" style="height: 100%">
        <div class="columns" style="width: 100%">
            <div class="column vertical-top text-left" style="width: 100%">
<br>
<p>Loss functions quantify the difference between predicted values and expected values (i.e., grounded truth)</p>
<br>
<p>Absolute value of the difference</p>
$$
L_{1}(\hat{y}, y) = |\hat{y} - y|
$$
<br>
<p>Squared difference</p>
$$
L_{2}(\hat{y}, y) = (\hat{y} - y)^2
$$
<br>
<p>Zero-One loss (classification error)</p>
$$
L_{0/1}(\hat{y}, y) = \begin{cases}
0 & \text{if } \hat{y} = y \\
1 & \text{if } \hat{y} \neq y
\end{cases}
$$
</div>
        </div>
    </div>
</div>

<br>
<p>Even the best hypothesis <em>h*</em> in <em><b>H</b></em> will have high error because:</p>
<br>
$$
\forall h \in H, \exists x: |h(x) - f(x)| > \epsilon

<br>
<p>where epsilon is some small positive number.</p>

<p>Overfitting occurs when our hypothesis space <em><b>H</b></em> is too complex, leading to:</p>
<br>
<p>Low empirical loss but high generalisation loss:</p>
<br>
$$
\text{EmpLoss}_{L,E}(h^*) \ll \text{GenLoss}_{L}(h^*)
$$
<br>
<p>The hypothesis <em>h*</em> memorizes the training examples instead of learning the true function <em><b>f</b></em>.</p>

<p>Regularisation transforms the loss function into a cost function that penalizes complexity to avoid overfitting</p>
<br>
$$
\text{Cost}_{L,\lambda}(h) = \text{EmpLoss}_{L,E}(h) + \lambda \cdot \text{Complexity}(h)
$$
<vr>
<p>Choosing the complexity function depends on the hypotheses space <em><b>H</b></em>. A good example for polynomials will be a function that returns the sum of the squares of coefficients.</p>

<div class="rows" style="height: 100%">

            <div class="column vertical-top text-left" style="width: 100%">
<p>Given the new cost function</p>
<br>
$$
\text{Cost}_{L,\lambda}(h) = \text{EmpLoss}_{L,E}(h) + \lambda \cdot \text{Complexity}(h)
$$
<br>
<p>The best hypothesis <em>h*</em> is the one that minimises the cost:</p>
<br>
$$
h^* = \underset{h \in H}{\operatorname{argmin}} \text{Cost}_{L,\lambda}(h)
$$
<p>where <em>λ</em> is a <b>hyperparameter</b> that controls the trade-off between fitting the data and model complexity and serves as a conversion rate.</p>
<br>
<p>Alternatives to mitigate overfitting are feature selection, hyperparameter tuning, splitting dataset in training, validation, and test data (e.g., cross validation algorithm).</p>
</div>
        </div>
    </div>

w_1 = \frac{n\sum_{i=1}^n x_i y_i - \sum_{i=1}^n x_i \sum_{i=1}^n y_i}{n\sum_{i=1}^n x_i^2 - \left(\sum_{i=1}^n x_i\right)^2}

<br>
<pre><code>Gradient Descent Algorithm:
Initialize w randomly
repeat
    for each w[i] in w
        Compute gradient: g = ∇Loss(w[i])
        Update weight:   w[i] = w[i] - α * g
until convergence
</code></pre>
<br>
<p>The size of the step is given by the parameter α, which regulates the behaviour of the gradient descent algorithm. This is a hyperparameter of the regression model we are training, usually called <em>learning rate.</em></p>

<p>An <b>epoch</b> is defined as one complete pass through the entire dataset during the training process. Multiple epochs are needed for the model to converge to an optimal solution.                 <p>The algorithm updates <b><em>W</em></b> using the entire dataset in each iteration.</p>

```python
import numpy as np
def batch_gradient_descent(X, y, alpha=0.01, epochs=1000):
    """
    X: numpy array of shape (n_samples, n_features)
    y: numpy array of shape (n_samples,)
    alpha: learning rate
    epochs: number of passes over the data
    Returns: w (numpy array of shape (n_features,))
    """
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    for epoch in range(epochs):
        grad = [0] * len(w)
        for i in range(n_samples):
            x_i = X[i]
            y_i = y[i]
            prediction = dot(w, x_i)
            error = prediction - y_i
            for j in range(len(w)):
                grad[j] += error * x_i[j]
        for j in range(len(w)):
            grad[j] /= len(n_samples)
            w[j] -= alpha * grad[j]
    return w
```

```python
import numpy as np
def stochastic_gradient_descent(X, y, alpha=0.01, epochs=1000):
    """
    X: numpy array of shape (n_samples, n_features)
    y: numpy array of shape (n_samples,)
    alpha: learning rate
    epochs: number of passes over the data
    Returns: w (numpy array of shape (n_features,))

    w = np.zeros(n_features)
    for epoch in range(epochs):
        for i in range(n_samples):
            x_i = X[i]
            y_i = y[i]
            prediction = np.dot(w, x_i)
            error = prediction - y_i
            for j in range(n_features):
```

                <p>The algorithm updates <b><em>W</em></b> after computing the gradient for a small batch of training examples (batch size <em>m</em>). The batch size is another hyperparameter.</p>

```python
import numpy as np
def mini_batch_gradient_descent(X, y, alpha=0.01, epochs=1000, batch_size=32):
    """
    X: numpy array of shape (n_samples, n_features)
    y: numpy array of shape (n_samples,)
    alpha: learning rate
    epochs: number of passes over the data
    batch_size: number of samples per batch
    Returns: w (numpy array of shape (n_features,))
    """
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    for epoch in range(epochs):
        indices = np.arange(n_samples)
        np.random.shuffle(indices)
        X_shuffled = X[indices]
        y_shuffled = y[indices]
        for start in range(0, n_samples, batch_size):
            end = start + batch_size
            X_batch = X_shuffled[start:end]
            y_batch = y_shuffled[start:end]
            y_pred = X_batch @ w
            error = y_pred - y_batch
            grad = X_batch.T @ error / len(X_batch)
            w -= alpha * grad
    return w
```
